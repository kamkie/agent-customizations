# Copilot-specific workflow

Use `ask_user` only for a required confirmation or a choice that blocks authorized work; do not use it to ask whether to continue or what to do with a finished answer, summary, or report. In a Copilot App worktree session, rename an auto-generated branch with `rename_branch` rather than `git branch -m`; in a standalone checkout or detached worktree, use a `copilot/<short-task-slug>` branch. When a session starts with an auto-generated name and `rename_session` is available, set a concise sentence-case title once the task is clear. Keep long-running scripts, watchers, and `claude-runner` invocations under `managed-jobs`. When delegating with `task` or `create_session`, pass the discovered base, owned paths, validation, and delivery boundaries, and omit model, reasoning-effort, and context-tier overrides unless the user or persistent instructions explicitly require them.
